# Paper Layout and Quotations

Use when setting up or auditing an MLA paper. Checked 2026-10-25.

## Evidence boundary

The current [formatting landing page](https://style.mla.org/formatting-papers/) sends readers to a
[free MLA 9 chapter](https://mlahandbookplus.org/books/book/5/chapter/56247/Introduction-to-Formatting-Your-Research-Project),
which returned HTTP 403 during this research. The defaults below use MLA's accessible
[archived formatting PDF](https://style.mla.org/app/uploads/sites/3/2020/12/Formatting-a-Research-Paper_v3_-The-MLA-Style-Center.pdf),
which predates MLA 9. Do not represent them as a direct audit of the current chapter.

## Working baseline

Follow instructor requirements first. Use one-inch margins, readable type with distinct italics
(12-point Times New Roman is an example, not the only permitted font), and double spacing throughout.
Keep text left-aligned; indent paragraph first lines half an inch. Put student, instructor, course,
and date on separate lines at upper left; center the paper title without decorative styling.
A separate title page is ordinarily unnecessary; confirm group-project or assignment requirements.
Use a repeating surname/page-number header at upper right, half an inch from the top.
Continue page numbering into the source list. Start Works Cited on a new page, center its heading,
and use half-inch hanging indents. Do not create indents with repeated spaces.

The [MLA 9 running-head discussion](https://style.mla.org/adapt-mla-running-heads/) independently
confirms surname plus page number. For internal headings, use consistent descending visual prominence,
left alignment, title capitalization, concise parallel wording, and multiple instances of each
internal level. Headings are optional; do not force APA's five-level system onto MLA.
See [heading guidance](https://style.mla.org/styling-headings-and-subheadings/) and
[MLA 9 discussion of parallel headings](https://style.mla.org/parallel-headings/).

## Quotation decisions

| Material | Run in | Block treatment |
|---|---|---|
| Prose | Up to four lines in the paper's normal layout | More than four lines |
| Poetry | Up to three verse lines; separate lines with spaced slashes | Four or more verse lines; preserve line breaks |

For prose, measure actual rendered lines, never a forty-word threshold. The accessible
[prose threshold post](https://style.mla.org/font-type-size-block-quotations/) explicitly concerns
MLA 8. The [2021 poetry guidance](https://style.mla.org/eliding-lines-in-poetry-quotations/)
confirms the distinct verse threshold. Set blocks half an inch in from the left, double-spaced,
without enclosing quotation marks. Put a block's parenthetical citation after its closing punctuation;
for an ordinary run-in quotation put the citation before the sentence's final period.
The archived PDF supports indentation; punctuation edge cases need the current handbook if disputed.

## Render inspection

Inspect the first page, a later page, a block quote, and the source list in the exported artifact.
Check repeat headers, title position, margins, line spacing, paragraph/hanging indents, page breaks,
italics, and DOI/URL wrapping. Recheck the prose block threshold after font or width changes.
If only Markdown/text is available, deliver content plus explicit word-processor settings and mark
pagination and geometry unverified. A Markdown block quote alone cannot establish half-inch indentation.
