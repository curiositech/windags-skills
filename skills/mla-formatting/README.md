# MLA Formatting Skill

A focused MLA 9 paper and citation workflow with dated official sources, examples, and a working scaffold.
Start with [SKILL.md](SKILL.md); load references only for the relevant task.
The bundle uses no scripts or external packages. It cannot certify visual formatting from plain text,
replace an instructor's requirements, or establish permission to use AI. Current handbook access limits
are recorded in [references/sources.md](references/sources.md).
