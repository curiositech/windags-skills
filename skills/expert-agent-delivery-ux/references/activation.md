# Activation examples

## Activate

1. “Design the workflow for Iris to build a complete portfolio with me approving the public launch.”
2. “My agent should own the site’s accessibility and hand me evidence it really passed. What do I see as it works?”
3. “I left while the agent was building. Show what happens if I return on my phone, request changes, and then publish.”
4. “Make approval and rollback understandable when an expert has updated our booking site.”
5. “Design how a specialist pauses a long-running build, asks for one piece of access, and resumes without making me pick technical details.”

## Route elsewhere

1. “Pick a staffing model for our worker agents and write internal on-call procedures.” → operational agent ownership.
2. “Implement a retry job for our test runner.” → CI implementation.
3. “Rewrite the agent’s introduction so it sounds less stiff.” → copy or voice design.
4. “How should Edie and Iris take turns in the same conversation?” → multi-agent conversation UX.
5. “How can Iris remember a preference across my architecture and photography projects?” → relationship, scope, and memory UX.
