# Skill Architecture Strategies

Choose the lightest strategy that materially improves execution quality:

| Need | Strategy |
|---|---|
| Better routing | Tighten description and NOT-for boundaries |
| Better expert behavior | Add decision points, failure modes, and worked examples |
| Deterministic setup | Move preflight logic into scripts |
| Heavy detail | Extract into focused reference files |
| Better review | Add Mermaid or structured output only when it helps |

Upgrade order:
1. Activation precision
2. Structural clarity
3. Expert discriminations
4. Support artifacts
5. Validation and changelog
