# Activation cases

Use these examples as a human-reviewed activation rubric. An agent platform must be tested separately to measure real routing.

| Expected | Query | Reason |
| --- | --- | --- |
| Activate | “How can Iris know me across two client projects without reading both?” | Stable identity and project boundary |
| Activate | “Design the memory controls before a private project becomes shared.” | Widening an audience |
| Activate | “What happens when I reopen a scoped agent job from a push on another device?” | Resumption and scope |
| Activate | “How should a DM with an agent relate to a team project?” | Distinct audiences and memory |
| Activate | “Design the ‘what this agent can see’ drawer for an enterprise workspace.” | Visible read and action scope |
| Skip | “Make the assistant learn my editing style from accepted drafts.” | Use longitudinal personalization |
| Skip | “Choose HNSW parameters for memory retrieval.” | Retrieval implementation |
| Skip | “Determine whether Edie or Vera should reply to a group mention.” | Use multi-agent conversation UX |
| Skip | “Animate Iris’s pointer as she points to a canvas block.” | Use embodied presence UX |
| Skip | “Assign an expert to ship a website end to end.” | Use expert delivery UX |
