# APA paper layout

Checked 2026-10-25. Follow assignment or publisher instructions and label departures.
Sources and refresh dates are cataloged in [sources.md](sources.md).

## Choose the paper type

| Element | Student | Professional |
|---|---|---|
| Title page | Title, author, department/institution, course number/name, instructor, due date | Title, author(s), research affiliation(s), author note |
| Header | Page number; running head only if requested | Running head and page number |
| Abstract | Usually omitted unless requested | Include as required for the manuscript/publication |

The title is centered, bold, title case, three to four lines below the top. Leave
one double-spaced blank line before the byline. Center the following title-page
identification lines. On professional papers connect different author affiliations
with superscript numbers when needed; the author note belongs in the lower half.
[Title page](https://apastyle.apa.org/style-grammar-guidelines/paper-format/title-page).

Number every page at top right, starting with 1 on the title page. A running head
is left aligned, uppercase, at most 50 characters including spaces and punctuation,
and has no “Running head:” label; use the same header on the first page.
[Page header](https://apastyle.apa.org/style-grammar-guidelines/paper-format/page-header).

## Set the document styles

- Use 1-inch margins, subject to institutional thesis/binding requirements.
  [Margins](https://apastyle.apa.org/style-grammar-guidelines/paper-format/margins).
- Choose a consistent readable font. APA's February 2026 font page includes
  12-point Aptos, 11-point Calibri/Arial, 10-point Lucida Sans Unicode, 12-point
  Times New Roman, 11-point Georgia, and normal 10-point Computer Modern.
  Figure lettering, code, and automatic footnotes have exceptions.
  [Font](https://apastyle.apa.org/style-grammar-guidelines/paper-format/font).
- Double-space body, references, quotations, headings, and table/figure labels,
  titles, and notes; remove extra paragraph spacing. Table cells may use single,
  1.5, or double spacing; automatic footnotes may retain their default settings.
  [Spacing](https://apastyle.apa.org/style-grammar-guidelines/paper-format/line-spacing).
- Align body text left with an uneven right edge; first-line indent 0.5 inch.
  Abstract opening paragraphs are not indented; reference entries instead use
  0.5-inch hanging indents. Use paragraph settings rather than typed spaces.
  [Paragraphs](https://apastyle.apa.org/style-grammar-guidelines/paper-format/paragraph-format).

Generally order title page, abstract if needed, text, references, footnotes,
tables, figures, appendices. Tables/figures may instead be embedded after first
mention; footnotes may appear at the page bottom. Start major elements on new
pages. [Order](https://apastyle.apa.org/style-grammar-guidelines/paper-format/order-pages).

## Headings and references

Use levels in order; do not number them or force headings into short papers.
Repeat the paper title at the first text page; do not add an “Introduction” heading.

| Level | Appearance | Following text |
|---|---|---|
| 1 | Centered, bold, title case | New paragraph |
| 2 | Left, bold, title case | New paragraph |
| 3 | Left, bold italic, title case | New paragraph |
| 4 | Indented, bold, title case, ends with period | Same line |
| 5 | Indented, bold italic, title case, ends with period | Same line |

Set accessible heading styles; keep headings double-spaced without added blank
lines. [Headings](https://apastyle.apa.org/style-grammar-guidelines/paper-format/headings).

Start the reference section on a new page with centered bold “References.”
Alphabetize entries by the first element, usually author surname. Use one paragraph
per entry with hanging indent and double spacing, without extra space between
entries. [Reference list](https://apastyle.apa.org/style-grammar-guidelines/paper-format/reference-list).

## Tables and figures

Number tables in first-mention order; put a bold number above an italic title-case
title. Supply column headings and needed explanatory notes below. Use sparse
horizontal rules and no vertical rules or boxed cells. Build real tables rather
than aligning with spaces. Embed after callout or place each on a separate page
after references; repeat header rows on multipage tables. APA gives tables and
figures the same overall number/title/note structure; figure-specific details
require consulting the official figure guidance before finalization.
[Table setup](https://apastyle.apa.org/style-grammar-guidelines/tables-figures/tables).

## Rendered inspection

Inspect actual page size/margins, font/style consistency, automatic numbering,
first-page header, title-page alignment, heading hierarchy, indentation, reference
hanging indents, page breaks, and table width/continuation. A Markdown table is an
explanatory illustration; it does not prove the destination file uses APA borders.
