# APA reference patterns and exceptions

Checked 2026-10-25. Angle-bracket fields below are placeholders, never real sources.

## Build from the source type

Most entries have author, date, title, and source. Transcribe surname/initials in
source order. List all authors through 20; for 21 or more list the first 19,
then an ellipsis and the last author, without an ampersand before that last name.
Use the full group name in references, even when text uses an abbreviation.
Retrieval dates belong only to unarchived works designed to change; a content
update date differs from a review date. [Reference elements](https://apastyle.apa.org/style-grammar-guidelines/references/elements-list-entry).

| Type | Pattern and judgment |
|---|---|
| Journal article | Author, A. A., & Author, B. B. (Year). Article title in sentence case. *Journal Title, volume*(issue), pages. DOI |
| Article number | Replace the page range with `Article <number>`; do not invent pagination. |
| Whole book | Author, A. A. (Year). *Book title in sentence case* (2nd ed.). Publisher. DOI if present |
| Edited-book chapter | Chapter Author, A. A. (Year). Chapter title. In E. E. Editor (Ed.), *Book title* (pp. xx–xx). Publisher. DOI if present |
| Online hosted video | Uploading Account. (Year, Month Day). *Video title* [Video]. Hosting Site. URL |
| Webpage | Author or Group. (Year, Month Day). *Page title in sentence case*. Site Name. URL |

For journals, italicize journal name and volume, not issue or article title. Include
an issue when available. [Articles](https://apastyle.apa.org/style-grammar-guidelines/references/examples/journal-article-references).
For books, edition is not italicized; omit publisher location. An ebook's device
or platform does not determine a different pattern.
[Books](https://apastyle.apa.org/style-grammar-guidelines/references/examples/book-references).
For webpages, omit site name if identical to the author; use a content-specific
publication/update date, not a sitewide footer or review date. News sites and
newspaper articles may require different source categories.
[Webpages](https://apastyle.apa.org/style-grammar-guidelines/references/examples/webpage-website-references).

For an edited-book chapter, cite the chapter author, not the editor; edition and
page range share parentheses. A chapter from a wholly authored book ordinarily
uses a whole-book reference instead.
[Edited chapters](https://apastyle.apa.org/style-grammar-guidelines/references/examples/edited-book-chapter-references).
For a hosted user video, the uploader is the reference author even if another
person speaks; identify the speaker in text when useful and use a timestamp for
a quoted passage. This does not automatically cover films or TV episodes.
[Hosted video](https://apastyle.apa.org/style-grammar-guidelines/references/examples/youtube-references).

## Missing information is not permission to invent

| Actually absent after checking | Adaptation |
|---|---|
| Author | Move title to author position; use title in text. Use “Anonymous” only when signed that way. |
| Date | Use `(n.d.)`; never substitute the day you accessed it. |
| Title | Supply a concise bracketed description. |
| Several of these | Combine the corresponding adaptations. |
| Retrievable source | Find a recoverable alternative; a genuine personal exchange may use personal-communication treatment. |

Distinguish “absent from the work” from “not yet supplied or checked.” For the
latter, mark the draft unresolved and request the missing field instead of
pretending no author/date exists. [Missing information](https://apastyle.apa.org/style-grammar-guidelines/references/missing-information).

## DOI, URL, and access date

Use `https://doi.org/<registered-DOI>` when a DOI exists, including for print use;
prefer it over a URL. With no DOI, ordinary academic-database articles usually
end after the pages; do not append a session/login URL. Public web works use a
direct stable URL. Proprietary or limited-circulation databases have exceptions.
Do not put a period after DOI/URL. Ordinary URLs do not need “Retrieved from.”
[DOIs and URLs](https://apastyle.apa.org/style-grammar-guidelines/references/dois-urls).
A needed retrieval statement is `Retrieved Month Day, Year, from URL`; it is
not required for every website. See the reference-elements source above.

## Generative AI: dated guidance

APA's September 9, 2025 reference guidance, checked 2026-10-25, separates:

- Specific helpful shareable chat: Company. (Year, Month Day). *Chat title*
  [Generative AI chat]. Tool or model. Chat URL
- General tool: Company. (Year). *Tool or model* [Large language model]. Tool URL

Use the chat's occurrence/conclusion date; for a tool use its update year, or the
website/app copyright year if no update date is indicated. Do not guess these
facts or a model identifier. A version number is no longer required by default.
Describe relevant use in the paper; report prompts in text or supplemental material
when useful, rather than stuffing them into the reference. Choose general-tool
citation when sharing a chat would compromise confidentiality.
[Current AI reference guidance](https://apastyle.apa.org/blog/cite-generative-ai-references).

Citation format does not grant permission to use AI. Check instructor, institution,
and publisher policies separately; verify generated claims against real sources.
[AI permission guidance](https://apastyle.apa.org/blog/cite-generative-ai-allowed).
The old [2023 ChatGPT post](https://apastyle.apa.org/blog/how-to-cite-chatgpt) is
explicitly archived. Recheck the current series when applying these evolving rules.
