# APA activation evaluations

These are authored evaluation cases with expected outcomes, not evidence that a
runtime activation experiment has been executed. Run them after metadata changes.

| Positive query | Expected behavior |
|---|---|
| “Format my psychology course paper in APA 7.” | Activate; establish student setup/rubric; format supported content and disclose rendering limits. |
| “Does my APA professional manuscript need a running head?” | Activate; explain professional header; do not apply student defaults. |
| “Repair these APA references; several authors and dates are missing.” | Activate; verify actual missingness, adapt entries, flag unverified fields. |
| “Show APA in-text citations for a three-author article and a 40-word quotation.” | Activate; apply abbreviation and inclusive block boundary; require authentic locator. |
| “How should I cite this AI chat in APA under current guidance?” | Activate; check current official AI series and distinguish citation from institutional permission. |

| Negative query | Expected behavior |
|---|---|
| “Create MLA Works Cited entries for these books.” | Do not activate APA; route to MLA formatting. |
| “Use Chicago footnotes for my history chapter.” | Do not activate; use Chicago guidance. |
| “Make this email warmer and shorter.” | Do not activate; edit prose without imposing academic style. |
| “Find studies proving my unsupported claim.” | Do not activate as APA formatting; use a research workflow without guaranteeing the claim. |
| “Certify this plain Markdown as a perfectly formatted DOCX.” | Do not offer APA certification; explain that final-file inspection is required and offer bounded content/layout help. |
