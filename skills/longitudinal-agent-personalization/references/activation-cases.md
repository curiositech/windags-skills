# Activation cases

These are expected classifications for reviewing skill descriptions. They are not a measured activation result.

| Expected | Query | Reason |
| --- | --- | --- |
| Activate | “How should Iris infer my visual taste from several rounds of edits?” | Inferred preference |
| Activate | “What should the agent remember when I change roles?” | Temporal facts and correction |
| Activate | “Design the UI that explains why a draft uses a preference.” | Explanation and control |
| Activate | “How can users make an agent forget something for real?” | Suppression, deletion and derivatives |
| Activate | “Evaluate whether the assistant gets better over a dozen sessions.” | Longitudinal measurement |
| Skip | “How can a private conversation stay separate when I share this project?” | Use scoped relationship design |
| Skip | “Set up a vector database for long-term recall.” | Retrieval infrastructure |
| Skip | “Train our foundation model on a company corpus.” | Model training |
| Skip | “Decide whether a notification should interrupt for an agent handoff.” | Use conversation or delivery UX |
| Skip | “Create an animated agent avatar and follow mode.” | Use embodied presence UX |
