# Evidence and precedents

Product documentation checked November 6, 2026. These observations describe documented capabilities and published studies. Product documentation establishes the feature and the intended interaction, while outcomes in a new project require testing.

| Source and evidence type | Documented pattern | Application and boundary |
| --- | --- | --- |
| [Poe Creator Platform changelog](https://creator.poe.com/changelog), shipped SDK | Sender identifiers are supplied in multi-bot messages. | Preserve the speaker as structured data across messages and receipts. This establishes a platform capability. Exact consumer controls and permissions need their own verification. |

A private source still needs a separate disclosure decision. |
| [Devin Slack integration](https://docs.devin.ai/integrations/slack), shipped integration | A mention starts a session. A linked Slack thread and web session can sync messages in both directions. ## Prototype research

| Study | Design and reported finding | Transfer limit |
| --- | --- | --- |
| Chaves and Gerosa, [Single or Multiple Conversational Agents?](https://experts.nau.edu/en/publications/single-or-multiple-conversational-agents-an-interactional-coheren/), CHI 2018 | A Wizard of Oz tourist-information study with 24 participants compared one conversational façade with multiple domain specialists. The authors found no significant difference in interactional coherence and reported more confusion and turn-organizing behavior with multiple visible specialists. | One scripted, short task with a small sample. The result motivates explicit turn ownership and a test of the cost of switching speakers. |
| Clarke et al., [One Agent Too Many](https://arxiv.org/html/2401.07123v1), author preprint, 2024 | A 19-person pilot compared automatic routing with a requirement to pick an agent across digital-assistant tasks. It reported higher usability for automatic routing. | The pilot recruited in a computer science department and describes the automatic condition first. Routine query routing differs from long-running collaboration. Test direct access as an option alongside automatic routing. |
| Houde et al., [Controlling AI Agent Participation in Group Conversations](https://arxiv.org/abs/2501.17258), IUI 2025 author manuscript | Two group-ideation studies examined controls over AI intervention. Participants wanted influence over when and where the agent contributed and disliked over-participation. | One AI with multiple people is an analogy about interruptions and user control. Use it to formulate testable timing rules for agent teams. |

## Design inference

- Start with **one reply owner and explicit specialist credit**. Compare the result with an opt-in group mode on a task where disagreement matters. Measure whether people can identify the current owner, audience and next action, alongside task completion and time.
- Treat **parallel work and parallel conversation as separate decisions**. Parallel research can yield a concise comparison, while parallel editing needs concurrency control and a visible conflict policy.
- Treat **an interruption as a user decision about attention**. Document priority and preferences for each notification category, and include users who continue on mobile hours later.
- Evaluate early across a wide desktop, a narrow phone and a background return from a notification. Check route comprehension, accessibility, privacy and re-entry as separate outcomes.
